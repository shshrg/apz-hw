###Task 1. Microservices Basics
This project contains 3 separate web apps: facade_service, logging_service, counter_service. To start the system, run each app in a separate terminal:
```
python ./facade.py
```
```
python ./logging.py
```
```
python ./counter.py
```
By default, the services use the following ports:
- facade_service: 8080
- counter_service: 8081
- logging_service: 8082
